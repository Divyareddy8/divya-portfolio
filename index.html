selected work

Llama-Style Transformer, from Scratch

PyTorch RoPE GQA / MQA SwiGLU

Built a decoder-only transformer entirely in raw PyTorch — no nn.Transformer, no HuggingFace — with RoPE, RMSNorm, SwiGLU, grouped/multi-query attention, and an incremental KV cache.

  • Verified KV-cache correctness against a full forward pass to a max absolute difference of ~6e-8, and benchmarked up to 5.6× faster generation at 256 tokens.
  • Ran controlled ablations across RoPE vs. sinusoidal embeddings, RMSNorm vs. LayerNorm, SwiGLU vs. GELU, and MHA vs. GQA vs. MQA — measuring loss, throughput, and memory trade-offs.

Distributed Training Framework

PyTorch DDP AMP Grad Checkpointing

A multi-GPU / multi-node training framework built from scratch with DistributedDataParallel, gradient accumulation, mixed-precision training, and per-block gradient checkpointing.

  • Built a benchmarking suite sweeping AMP and checkpointing configurations, tracking throughput, GPU utilization, and memory via torch.profiler and an NVML-based sampler.
  • Added experiment tracking with automatic fallback across logging backends, plus atomic checkpoint save/resume — smoke-tested end-to-end with real multi-process DDP.

Multimodal RAG System

FAISS BM25 Cross-Encoder

A production-grade Retrieval-Augmented Generation pipeline handling PDFs, images, tables, and web pages — with dedicated parsers, OCR, and semantic chunking.

  • Implemented hybrid retrieval combining dense (FAISS) and sparse (BM25) search via Reciprocal Rank Fusion, followed by cross-encoder reranking for precision.
  • Designed an agentic retrieval loop with HyDE and multi-query expansion, LLM tool-calling, and an evaluation framework scoring faithfulness, relevance, and recall.

Distributed Job Queue

Node.js Redis Docker / K8s

A production-grade distributed task processing system on Redis, with priority scheduling across specialized worker pools and atomic Lua scripts to eliminate race conditions under concurrent load.

  • Fault-tolerant by design: sliding-window rate limiting, visibility timeouts for stuck jobs, and Kubernetes HPA manifests for dynamic worker scaling.
  • Dead-letter queue with replay, exponential backoff retries, and a live queue-health dashboard driven by server-sent events.

Multithreaded Web Server

C++ POSIX Sockets Pthreads

A high-performance web server built from scratch in C++ on raw POSIX sockets, with a thread pool for concurrent requests and zero external library dependencies.

  • RAII socket guards for leak-free resource management and graceful shutdown.

Foreground–Background Separation in Video

OpenCV scikit-learn RPCA

Implemented and benchmarked three background-subtraction algorithms — Mean, Median, and RPCA — across real-world video datasets.

  • RPCA's low-rank + sparse decomposition (Inexact ALM) outperformed baselines by 15–20% IoU, reaching 88–93% F1-score under illumination variation.
  • Modeled foreground extraction as a convex optimization problem (nuclear norm + ℓ1 minimization), evaluated across four CDnet 2014 categories.
